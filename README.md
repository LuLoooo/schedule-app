# 日程管家 · 自然语言日程 & 里程记录

一个**纯前端、可安装到手机主屏**的日程管理 Web App。用大白话（如"明早 9 点去拍摄，开车 5 公里"）就能记日程、算里程、自动分类，支持日 / 周 / 月视图，还能像原生 App 一样"安装"到桌面。

> 无需服务器、无需注册、无后端。**所有数据只存在你自己的设备本地**，卸载 App 才会清除。

---

## ✨ 功能特性

- **自然语言输入**：一句话拆成多条日程，自动识别时间、地点、里程。
- **智能分类**：策划 / 拍摄 / 剪辑 / 摸鱼 / 其他，可**自定义增删改**（含自动归类关键词）。
- **多视图**：日视图（连续时间条，不切格）、周视图、月视图（固定格子，长标题自动换行）。
- **里程记录**：输入"开车 5 公里"自动记录并换算油费。
- **多账户 + 跨账户查看**：账户数据隔离；可切到"全部账户"合并查看，每条带归属标签。
- **数据导出 / 导入**：JSON / CSV / HTML，方便备份。
- **可安装 PWA**：添加到手机主屏即全屏使用，且**离线可用**。

## 📲 安装到手机（当 App 用）

### Android（Chrome / Edge）
1. 用浏览器打开下方部署好的网址。
2. 点地址栏右侧的 **安装图标**，或点页面右上角 **📲 安装** 按钮。
3. 桌面 / 主屏就会出现"日程管家"图标，点开即全屏 App。

### iPhone / iPad（Safari）
1. 用 Safari 打开网址。
2. 点底部 **分享** 按钮 → **添加到主屏幕**。
3. 主屏出现图标，点开即全屏 App（iOS 暂不支持自动安装按钮，需手动添加到主屏幕）。

> 安装后数据保存在该 App 的本地存储中，**只要不卸载、不清缓存，数据一直都在**。

## 🚀 自己部署（让别人也能用）

本项目是纯静态文件，放到任意静态托管即可。最方便的是 **GitHub Pages**（免费、自带 HTTPS、可被"安装"为 App）。

### 方式一：GitHub Pages（推荐，零成本）

1. 把本仓库推送到你的 GitHub（见下方"推送到 GitHub"）。
2. 在仓库 **Settings → Pages**：
   - Source 选 **Deploy from a branch**
   - Branch 选 **main**（或 master），目录选 **/ (root)**
   - 点 **Save**
3. 等待约 1 分钟，访问 `https://<你的用户名>.github.io/<仓库名>/` 即可。
4. 把这个链接发给别人，他们就能打开并安装。

### 方式二：任意静态服务器 / 网盘
只要能托管 `index.html` 及同目录文件即可，例如：
```bash
# 本地预览
python3 -m http.server 8090
# 然后浏览器打开 http://localhost:8090
```
> 注意：Service Worker 离线缓存需要 `http://` 或 `https://` 环境（`file://` 直接打开无法安装）。

## 🔐 数据存储与隐私

- 数据保存在浏览器的 **localStorage**，按"账户"命名空间隔离。
- **完全本地**：没有服务器、不上传任何数据，隐私可控。
- **持久性**：只要不卸载 App、不清浏览器数据、不换无痕模式，数据长期保留。
- **备份建议**：在 App 内用"导出"功能把数据存成 JSON 文件，换设备或清缓存后可"导入"恢复。

## 💻 技术栈

- Vue 3（本地引入，无 CDN 依赖，可离线）
- 原生 CSS（含移动端适配）
- 纯 JavaScript 自然语言解析 / 排程引擎
- PWA：manifest + Service Worker 离线缓存
